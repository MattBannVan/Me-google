# Me-google Agent Instructions

## Purpose
Me-google is a multi-platform AI xrOS - an operating system extended into virtual reality by xr-intelligence group.

## Contribution Guidelines
1. Align with privacy, XR integration, and AI features.
2. Add or improve code for VR object creation, real-time sharing, anonymous hosting.
3. Use skills like quest-vr-builder for VR features.
4. Commit changes and create PR back to source.

## Initial Contribution
Added AGENTS.md to guide future AI agents in contributing to the xrOS project.

Follow these to make meaningful contributions to the Me-google ecosystem.
